# 🥭 محرك ألعاب Mango DSL 2D للأندرويد

محرك ألعاب ثنائي الأبعاد (2D Game Engine) متكامل مصمم خصيصاً لهواتف الأندرويد، يتيح تصميم وبرمجة ألعاب 2D ضخمة واحترافية مباشرة من الهاتف أو عبر بيئات التطوير، ويدعم لغتين برمجة: **لغة بايثون (Python)** و**لغة البرمجة العربية الطبيعية (Arabic Game DSL)**.

---

## 🌟 أبرز مميزات المحرك

1. **نواة ألعاب عالية الأداء (60-120 FPS)**:
   * محرك رسم سريع مبني على `SurfaceView` مع معالجة زمنية دقيقة (`Delta Time`).
   * محرك فيزياء خفيف يدعم الجاذبية، القفز، الاحتكاك، وكشف التصادمات الصندوقية (`AABB Box Collision`).
   * كاميرا ذكية 2D مع ملاحقة ناعمة للشخصيات ونظام تكبير/تصغير (`Camera2D`).
   * أزرار تحكم لمسية افتراضية على الشاشة (D-Pad وأزرار تفاعلية S للقفز، A للتفاعل، B للهجوم).

2. **لغة البرمجة العربية الطبيعية (Mango Arabic DSL)**:
   * مفسر نحوي سريع يحلل الأوامر العربية ويحولها إلى شجرة أوامر (`AST`) فورية بدون أي تأخير.
   * صياغة بديهية تحاكي التفكير الطبيعي:
     * `إذا ضغط اللاعب "s" { اقفز بقوة 400 }`
     * `تحرك في اتجاه يمين بسرعة 200`
     * `إذا توفر عنصر "حجر_سحري" في المخزون { افتح الباب_الحجري }`
     * `عند_التصادم مع عملة_ذهبية { أضف عنصر "عملة" إلى المخزون }`

3. **دعم لغة بايثون (Python Game Scripting)**:
   * جسر برمجي للتحكم في كائنات اللعبة وفيزيائها بلغة بايثون القياسية:
     * `def on_start(entity): ...`
     * `def on_update(entity, dt): ...`
     * `def on_collision(entity, other): ...`

4. **استوديو متكامل بخمس واجهات تفاعلية**:
   * **🎮 المشغل الحي (Game Runner)**: تشغيل واختبار اللعبة مباشرة مع عداد الإطارات والتحكم اللمسي.
   * **🎨 محرر المشهد (Scene Editor)**: تعديل مواضع الكائنات، أحجامها، ألوانها، وصلابتها، وجاذبيتها.
   * **📝 محرر الأكواد (Code Studio)**: شريط وصول سريع لأوامر لغة الضاد وتبديل فوري بين العربي وبايثون.
   * **📁 مدير الأصول (Asset Manager)**: استيراد وتنظيم الرسوم، الشخصيات، والمؤثرات الصوتية.
   * **📖 قاموس الضاد (Dictionary)**: مرجع كامل وشامل لكل كلمة مفتاحية مع أمثلة قابلة للنسخ المباشر.

## 📖 قاموس وأوامر لغة البرمجة العربية للمحرك

### أ. أحداث دورة الحياة
| الكلمة المفتاحية | الوظيفة | مثال |
| :--- | :--- | :--- |
| `عند_البدء` | تنفيذ الأوامر لمرة واحدة عند بدء المشهد | `عند_البدء { الصحة = 100 }` |
| `في_كل_إطار` | تنفيذ الأوامر باستمرار في كل لحظة (60fps) | `في_كل_إطار { تحرك في اتجاه يمين بسرعة 150 }` |
| `عند_التصادم مع` | استجابة فورية عند لمس كائن آخر | `عند_التصادم مع حجر_سحري { دمر_الكائن هذا_الكائن }` |

### ب. مدخلات اللاعب والتحكم
| الكلمة المفتاحية | الوظيفة | مثال |
| :--- | :--- | :--- |
| `إذا ضغط اللاعب` | فحص ضغط زر معين (يمين، يسار، أعلى، أسفل، s، a، b) | `إذا ضغط اللاعب "s" { اقفز بقوة 400 }` |
| `إذا استمر الضغط على` | فحص الضغط المتواصل للحركة المستمرة | `إذا استمر الضغط على "يمين" { ... }` |

### ج. الحركة والفيزياء
| الكلمة المفتاحية | الوظيفة | مثال |
| :--- | :--- | :--- |
| `تحرك في اتجاه` | تحريك الكائن (يمين / يسار / أعلى / أسفل / توقف) | `تحرك في اتجاه يمين بسرعة 200` |
| `تحرك نحو كائن` | ملاحقة ذكية لكائن آخر في الخريطة | `تحرك نحو كائن اللاعب بسرعة 100` |
| `اقفز بقوة` | قوة دفع للأعلى مع منع القفز المتكرر في الهواء | `اقفز بقوة 380` |
| `عطّل التصادم مع هذا_الكائن` | إلغاء الصلابة ليمر اللاعب من خلاله | `عطّل التصادم مع هذا_الكائن` |

### د. المخزون والعناصر والحالة
| الكلمة المفتاحية | الوظيفة | مثال |
| :--- | :--- | :--- |
| `إذا توفر عنصر ... في المخزون` | التحقق من وجود عنصر بحقيبة اللاعب | `إذا توفر عنصر "حجر_سحري" في المخزون { ... }` |
| `أضف عنصر ... إلى المخزون` | وضع عنصر جديد في حقيبة اللاعب | `أضف عنصر "حجر_سحري" إلى المخزون` |
| `احذف عنصر ... من المخزون` | استهلاك العنصر عند استخدامه | `احذف عنصر "حجر_سحري" من المخزون` |
| `افتح` | تغيير حالة كائن كالبوابات من مغلق لمفتوح | `افتح الباب_الحجري` |
| `دمر_الكائن` | حذف كائن نهائياً من المشهد | `دمر_الكائن هذا_الكائن` |
| `شغل صوت` | تشغيل مؤثر صوتي من الأصول | `شغل صوت "فتح_الباب"` |

## 🎮 اللعبة النموذجية المضمنة: «لغز الحجر السحري»

المحرك يأتي مجهزاً بلعبة كاملة توضح ربط الأوامر البرمجية العربية:
* **اللاعب**: يتحرك بالأسهم ويقفز بالزر `s`، يتأثر بالجاذبية.
* **الحجر السحري**: كائن بنفسجي متوهج عند لمسه يُضاف للمخزون ويختفي.
* **الباب الحجري**: بوابة حجرية مغلقة صلبة لا تسمح بالمرور، وعند لمسها تفحص المخزون:
  * إذا كان الحجر السحري متوفراً ← يُفتح الباب، يتغير لونه للأخضر، يُعطل التصادم ليمر اللاعب، ويُستهلك الحجر!
  * إذا لم يتوفر ← تظهر رسالة تنبيه للاعب تخبره بالحاجة للبحث عن الحجر أولاً.

## 🚀 طريقة البناء والتشغيل عبر Klencod IDE

المشروع جاهز للبناء المباشر:
1. افتح مشروع `MangoDSL` في **Klencod IDE**.
2. اختر مهمة البناء المباشرة:
   ```bash
   ./gradlew :app:assembleDebug
   ```
3. سيتم توليد ملف التطبيق `app-debug.apk` في المسار:
   `app/build/outputs/apk/debug/app-debug.apk`
